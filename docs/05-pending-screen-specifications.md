# Pending Screen Specifications Sign-off: UI Direction

Status: Placeholder, not a settled screen specification.

## Direction

- A dark burgundy global header anchors the brand; desktop navigation is a compact horizontal list and mobile content stacks naturally.
- Home starts with full-width food photography, the brand name, and two primary actions: order and reserve.
- Restaurant, Bakery, and Lounge use the same catalog surface: line-specific heading, category filters, search, and product tiles. Cards are limited to products, promotions, and gallery tiles.
- Gallery is an image grid; Promotions is a compact promotional list; About and Contact are unframed editorial sections.
- Cart remains a client-side side panel. Checkout opens a short form and produces a `wa.me` handoff; no data is posted to the API.
- Reservation is an unframed form page that produces the same type of handoff.

## Decisions requiring formal Screen Specifications

- Final logo artwork, photo art direction, exact section ordering, map provider/embed, final content copy, and the staff admin dashboard design.
- The current UI uses descriptive placeholder imagery and sample catalog content only, so the front end remains demonstrable before CMS data exists.
